Digittouch Shorts

A publishing tool by Digittouch Ent for the Mind Box YouTube channel.

What it does

Digittouch Shorts is a private tool that Digittouch Ent uses to manage its own YouTube channel, Mind Box. With the channel owner's permission, it:

  • uploads finished videos to the Mind Box channel;
  • fills in each video's title, description, tags and settings;
  • schedules videos to publish at set times.

It is used only by Digittouch Ent on its own channel. It is not offered to the public and does not access anyone else's account.

About Mind Box

Mind Box publishes short stories with a realistic life twist and a prompt for what to do next time.
